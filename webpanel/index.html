NO PORT FORWARDING

Set up the agent

Run the agent on the same PC as your Reclaimer server. It connects out to this panel, so your router does not need an open port.

PAIRING CODE

----

  1. Download the agent on the PC running the game server. Download OmniVaultAgent.exe
  2. Put it in a folder such as C:\OmniVaultAgent. No Node.js install or unzipping is needed.
  3. Open PowerShell in that folder and run the setup command shown here. It tests the local RCON connection, pairs the agent, and prompts for the RCON password. Add an Agent server first to get the code and command.
  4. Keep the agent running by double-clicking OmniVaultAgent.exe after setup. Keep its window open.
  5. Optional: enable Server files For a new agent, add --files-dir "C:\Path\To\Your\Server\Content" to setup. If it is already paired, run --set-files-dir "C:\Path\To\Your\Server\Content" and restart the agent. Only the owner can delete files.
  6. Optional: let the panel create Reclaimer servers Add --instances-dir "C:\OmniVault\instances" --reclaimer-exe "C:\Path\To\project-reclaimer-dedicated.exe" --server-root "C:\Path\To\Halo Server". The server root must contain game\ and content\. If it is already paired, use the --set-* equivalents and restart the agent.

SETUP COMMAND

If your RCON is not on port 49176, change --rcon-port in the command. The RCON password is never sent to the panel.

Optional: add --files-dir "C:\Path\To\Your\Server\Content" to the command to enable the Server files tab. The agent only accesses files inside that folder.

MANAGED SERVERS

Reclaimer instances

One-time agent setup. Stop the agent on the game-server PC, run this command with your real paths, then start the agent again. The panel never receives the RCON password or files outside these folders.

.\OmniVaultAgent.exe --set-instances-dir "C:\OmniVault\instances" --set-reclaimer-exe "C:\Path\To\project-reclaimer-dedicated.exe" --set-server-root "C:\Path\To\Halo Server"

The instances folder can be empty. The server root must be the Reclaimer folder that contains game\ and content\ (usually the folder holding the .exe). Restart the agent after saving.
